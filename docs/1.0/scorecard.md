# Scorecard

> [!NOTE]
> Weight configuration: CoE, Administrator. Viewing: PSM, Manager, Administrator. Partners can view their own scorecard through the Portal.

The Scorecard provides a quantitative view of partner performance. It aggregates metrics across multiple dimensions into a single weighted score that drives health assessments and path advancement decisions.

## How Scoring Works

Each scorecard metric has a **weight** that determines its contribution to the overall score. Weights are configured by admins and can be adjusted per path or partner tier.

| Dimension | Example Metrics |
|-----------|----------------|
| **Revenue** | Pipeline value, closed-won ratio, sourced vs influenced |
| **Delivery** | Project success rate, on-time completion, resource utilization |
| **Enablement** | Certifications achieved, training completion rate |
| **Engagement** | Event participation, QBR attendance, portal activity |

## Viewing the Scorecard

Navigate to **Plan > Scorecard** to see the scorecard for a selected partner.

<!-- ![Partner scorecard](images/scorecard.png) -->

The scorecard displays:

- Overall composite score
- Individual dimension scores
- Trend indicators (improving, stable, declining)
- Comparison to peer benchmark (anonymized)

## Scorecard Weights

Administrators configure scorecard weights under **Administration > Configuration**. Weights determine how much each dimension contributes to the composite score.

> [!TIP]
> Scorecard weights can be different for each partner tier. A newly onboarded partner might weight enablement heavily, while an advanced partner might weight revenue more.

## Scorecard and Gate Evaluation

Scorecard values are used as gate criteria for path advancement. For example, a gate might require a minimum composite score of 70 before a partner can advance to the next stage.
