# QBR Workbench

The QBR (Quarterly Business Review) Workbench provides a structured framework for conducting quarterly review sessions with partners.

## How QBRs Work

A QBR session is organized into sections, each covering a specific topic. Partner Manager provides a consistent structure so that every QBR covers the same key areas.

## Creating a QBR Session

1. Navigate to **Engage > QBR Workbench**
2. Click **New QBR Session**
3. Select the partner and quarter
4. The session is created with default sections

<!-- ![QBR session](images/qbr-session.png) -->

## QBR Sections

A typical QBR session includes sections for:

- **Performance Review** — Scorecard metrics, goal progress
- **Pipeline Review** — Opportunity status, deal registration activity
- **Delivery Review** — Project health, resource utilization
- **Enablement Review** — Certification progress, training completion
- **Action Items** — Agreed next steps and commitments

Each section can include notes, discussion points, and outcomes.

## Linking to Action Plans

After a QBR session, create an [Action Plan](action-plans) to track the agreed-upon next steps. This closes the loop between discussion and execution.

> [!TIP]
> Prepare for QBR sessions by reviewing the partner's scorecard, health dashboard, and task board beforehand. Partner Manager consolidates all the data you need in one place.

## QBR History

All QBR sessions are archived and accessible from the partner's profile. This provides a longitudinal record of the partnership's evolution.
