# Enablement Events

> [!NOTE]
> Available to: CoE, Administrator (creation and management). PSM, Manager (viewing and registration). Requires the `enablement_events_admin` feature flag for management and `enablement_events_user` for end-user access.

Enablement Events are training sessions, workshops, webinars, and courses organized for the partner portfolio. Events support multiple session types, Zoom integration, and AI-assisted design.

## Viewing Events

Navigate to **Engage > Enablement Events** to see upcoming and past events. CoE users and administrators also have access to the admin view at **Strategy & CoE > Enablement > Enablement Events**.

## Creating an Event

1. Click **Create Event**
2. Select the event type: **Workshop**, **Webinar**, or **Course**
3. Enter event details:
   - Title, description, and product area
   - Target audience and prerequisites
   - Duration and maximum participants
   - Materials URL and learning objectives
4. Click **Save**

### AI-Assisted Event Design

When [AI Agents](ai-agents) are enabled, the event creation form includes a **Generate with AI** option. Select a product area, audience, and topic, and the Enablement Designer agent will produce a complete event package including title, description, learning objectives, prerequisites, a time-blocked agenda, lab design, promotion copy, and instructor notes. All fields can be reviewed and edited before saving.

## Event Sessions

An event can have multiple sessions — individual scheduled occurrences with their own logistics:

- **Date and time** with timezone
- **Location** or meeting URL
- **Instructor** or facilitator assignment
- **Geography/Region** targeting
- **Maximum participants** and registration deadline
- **Notes** and post-session summary

### Zoom Integration

For workshop-type events, sessions can be linked to Zoom meetings:

- A Zoom meeting is automatically provisioned when a session is created
- The meeting link is attached to the session details
- Breakout rooms can be configured for small-group exercises
- Attendance tracking integrates with the Zoom participant list

See [Workshops & Labs](workshops) for additional workshop-specific features like labs and checkpoints.

## Registrations

Partners and their contacts can register for event sessions. Registrations can be:

- Created by the PSM on behalf of a contact
- Created by a CoE user when setting up the event
- Submitted by the partner through the [Partner Portal](portal-overview)

### Registration Statuses

| Status | Description |
|--------|-------------|
| **Registered** | Contact has signed up for the session |
| **Confirmed** | Attendance confirmed (manual or automated) |
| **Attended** | Participant completed the session |
| **No-Show** | Registered but did not attend |
| **Cancelled** | Registration was withdrawn |

## Event Analytics

After an event, review attendance and engagement metrics:

- Registration vs. attendance rate
- Partner distribution across sessions
- Feedback and ratings (if collected)

> [!TIP]
> Enablement event participation feeds into the partner scorecard under the engagement dimension. Upcoming sessions also appear on the Calendar tab of individual [partner profiles](partner-dashboard).
