# Path Reviews

> [!NOTE]
> Available to: PSM, Manager, Administrator. Path configuration is managed by CoE users.

Path Reviews are the formal process for evaluating whether a partner is ready to advance to the next stage in their path.

## When Reviews Happen

A path review is initiated when:

- A partner has met all gate criteria for their current stage
- A PSM believes a partner is ready and wants to formally evaluate
- A scheduled review date has been reached

## Starting a Review

1. Navigate to **Act > Path Reviews**
2. Click **New Review** or select a pending review
3. Select the partner and their current enrollment
4. The system displays the gate criteria and whether each is met

## Gate Evaluation

During a review, each gate criterion is evaluated:

| Criterion Type | Example |
|---------------|---------|
| **Scorecard** | Composite score >= 70 |
| **Certifications** | At least 3 certified practitioners |
| **Projects** | Minimum 5 completed projects |
| **Tasks** | 80% task completion rate |
| **Custom** | Other configurable criteria |

Gates that are met show a passing indicator. Gates that are not met show the gap.

## Approving Advancement

If all gates are met, the PSM can approve the advancement:

1. Review the gate evaluation results
2. Add any review notes
3. Click **Approve Advancement**
4. The partner moves to the next stage

> [!WARNING]
> Stage advancement triggers auto-population of new tasks from the next stage's templates. Make sure task templates are configured before advancing partners.

## Review History

Every review is recorded with:

- Date and reviewing PSM
- Gate evaluation results
- Decision (approved, deferred, declined)
- Notes

This provides a complete audit trail of a partner's progression decisions.
