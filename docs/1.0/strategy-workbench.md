# Strategy Workbench

> [!NOTE]
> Available to: CoE, Administrator. Requires the `strategy` feature flag to be active.

The Strategy Workbench is where the Center of Excellence creates and manages fiscal-year plans that define targets, budgets, initiatives, and scenarios for the partner ecosystem.

## Dashboard

The Strategy Dashboard provides an overview of your planning landscape:

- **Active plans** with status indicators (on-track, at-risk, behind target)
- **Upcoming reviews** scheduled for the current period
- **Key metrics** — aggregate target attainment, budget utilization, initiative completion
- Quick links to create new plans or view variance reports

## Plans

### Creating a Plan

1. Navigate to **Strategy & CoE > Strategy Workbench > Plans**
2. Click **Create Plan**
3. Enter the plan details:
   - **Title** — descriptive name (e.g. "FY26 Partner Growth Plan")
   - **Fiscal Year** — the target fiscal year
   - **Period Type** — annual or quarterly granularity
   - **Description** — context and objectives

New plans start in **Draft** status and can be edited freely.

### Plan Tabs

Each plan has a tabbed interface for managing its components:

#### Targets

Define measurable goals for the plan period:

- Add targets with a **name**, **metric type** (currency, count, percentage), and **planned value**
- Set values per quarter for quarterly plans
- Track **actual** values as they are reported
- Compare planned vs. actual with variance indicators

#### Assumptions

Document the planning assumptions that underpin your targets:

- Market growth rates, pricing expectations, competitive dynamics
- Resource availability and partner capacity projections
- Each assumption captures a planned value and can be revisited during reviews

#### Budgets

Allocate resources across categories:

- Break budgets down by category (co-marketing, enablement, headcount, etc.)
- Set quarterly allocations
- Track spend against allocation

#### Initiatives

Strategic projects that support the plan:

- Define initiatives with an **owner**, **start/end dates**, and **expected impact**
- Track initiative status (planned, in progress, completed, deferred)
- Link initiatives to specific targets they support

#### Reviews

Schedule periodic plan reviews:

- Set review dates and assign reviewers
- Capture review outcomes and action items
- Track review status (scheduled, completed, overdue)

#### Scenarios

Model alternative futures:

- Create what-if scenarios by adjusting targets, assumptions, or budgets
- Compare scenarios side-by-side
- Use scenario analysis to stress-test plans before committing

### Plan Lifecycle

| Status | Description |
|--------|-------------|
| **Draft** | Plan is being developed; all fields are editable |
| **Active** | Plan has been reviewed and is in execution |
| **Committed** | Plan is locked; changes require creating a new version |

### Committing a Plan

When a plan is finalized, commit it to lock the values and make it the active baseline. If changes are needed later, create a new **version** of the committed plan — this preserves the original baseline for comparison.

## Variance View

Navigate to **Plans > [Plan] > Variance** for a dedicated comparison of targets vs. actuals:

- Category-level breakdown with color-coded variance indicators
- Drill into specific targets to see quarterly progression
- Identify where execution diverges from plan
