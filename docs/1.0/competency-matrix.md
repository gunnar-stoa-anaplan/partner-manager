# Competency Matrix

The Competency Matrix maps a partner's skills and certifications across key capability areas. It provides a visual representation of where a partner is strong and where they need development.

## How It Works

The matrix displays capability areas as rows and proficiency levels as columns. Each cell shows whether the partner has met the requirements for that capability at that level.

<!-- ![Competency matrix view](images/competency-matrix.png) -->

## Capability Areas

Typical capability areas include:

- Platform fundamentals
- Solution design
- Model building
- Data integration
- Deployment and administration
- Industry-specific expertise

## Proficiency Levels

Each capability area has defined proficiency levels (e.g., Foundational, Intermediate, Advanced, Expert). Requirements for each level may include:

- Specific certifications
- Number of completed projects in that area
- Training course completions

## Linking to Paths

The competency matrix feeds into gate evaluation. A path gate might require a partner to have at least Intermediate proficiency in three or more capability areas before advancing.

> [!TIP]
> Use the competency matrix during QBR sessions to identify skill gaps and plan targeted enablement activities.
