# Task Board

> [!NOTE]
> Available to: PSM, Manager, Administrator

The Task Board is where PSMs manage the prescriptive and ad-hoc tasks for their partners. Tasks are the actionable units of work that drive partner progression.

## How Tasks Work

Tasks can be created in two ways:

- **Auto-populated** — Generated automatically from task templates when a partner is enrolled in a path or advances to a new stage
- **Manual** — Created by PSMs for ad-hoc work items

Each task has an owner, a due date, a status, and an optional link to a partner path stage.

## Viewing the Task Board

Navigate to **Plan > Task Board** to see all tasks across your portfolio. Tasks can be filtered by:

- Partner
- Status (open, in progress, completed, overdue)
- Priority
- Due date range

## Creating a Task

1. Click **New Task** on the task board
2. Select the partner
3. Enter the task title and description
4. Set the owner, due date, and priority
5. Click **Save**

## Task Auto-Population

When a partner advances to a new stage in their path, Partner Manager automatically creates tasks from the configured task templates for that stage. This ensures that every partner at a given stage has the same baseline set of tasks.

> [!NOTE]
> Task templates are configured by administrators under **Administration > Configuration > Task Templates**. See the [Configuration](configuration) page for details.

## Task Verification

Some tasks can be auto-verified — Partner Manager checks whether the completion criteria have been met (e.g., a required certification was achieved, a project was completed) and marks the task as done automatically.

## Task Comments

Team members can add comments to tasks for collaboration and tracking. Comments include timestamps and the author's name.
