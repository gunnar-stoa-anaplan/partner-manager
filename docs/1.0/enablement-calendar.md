# Enablement Calendar

> [!NOTE]
> Available to: CoE, Administrator. Requires the `enablement_events_admin` feature flag.

The Enablement Calendar provides a centralized view of all scheduled enablement activities — events, workshops, training sessions, and partner meetings.

## Calendar View

Navigate to **Enablement > Enablement Calendar** to see the global calendar. The calendar and event management features require the `enablement_events_admin` feature flag.

<!-- ![Enablement calendar](images/enablement-calendar.png) -->

The calendar supports:

- **Month, week, and day views** — Toggle between different time scales
- **Color coding** — Events are color-coded by type (training, workshop, meeting, etc.)
- **Filtering** — Filter by event type, partner, or facilitator

## Creating Events from Calendar

Click on a date to quickly create a new event:

1. Click the desired date
2. Enter event details
3. Add sessions if needed
4. Click **Save**

The event will appear on the calendar and be available for partner registration.

## Partner Calendar

Partners also have access to their own calendar view through the Partner Portal, showing events they are registered for or eligible to attend.

## Integration with Events

The calendar is tightly integrated with the [Enablement Events](enablement-events) system. All events created through the enablement management interface automatically appear on the calendar.

> [!TIP]
> Use the calendar during planning sessions to identify gaps in enablement coverage and ensure events are spread evenly across the quarter.
