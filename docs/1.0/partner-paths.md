# Partner Paths

Partner Paths are the backbone of Partner Manager's prescriptive approach. A path defines a structured maturity journey that a partner progresses through — from onboarding through to strategic partnership.

## How Paths Work

Each path consists of a series of **stages**, and each stage has **gates** — criteria that must be met before a partner can advance to the next stage. This gate-based progression ensures partners are genuinely ready before moving forward.

```
Onboarded → Developing → Established → Advanced → Strategic
    │            │             │            │           │
   Gate 1      Gate 2       Gate 3       Gate 4      Final
```

## Viewing Paths

Navigate to **Plan > Partner Paths** to see all available paths and their current enrollments.

## Enrolling a Partner

To enroll a partner in a path:

1. Navigate to the partner's profile
2. Click **Enroll in Path**
3. Select the appropriate path
4. The partner begins at the first stage

> [!WARNING]
> A partner must be enrolled in at least one path before tasks can be auto-generated from templates. Without a path enrollment, only manually created tasks will appear.

## Stage Advancement

When a partner meets all gate criteria for their current stage, a PSM can initiate a **path review** to advance them. Gate evaluation considers:

- Scorecard metrics meeting threshold values
- Required certifications achieved
- Minimum number of completed projects
- Task completion percentage
- Other configurable criteria

## Path History

Every stage transition is recorded in the partner's stage history, providing a complete timeline of their progression with timestamps and the reviewing PSM.

> [!TIP]
> Use the [Path Reviews](path-reviews) page under **Act** to manage pending advancement reviews across your portfolio.
