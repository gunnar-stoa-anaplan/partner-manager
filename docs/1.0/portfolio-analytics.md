# Portfolio Analytics

> [!NOTE]
> Available to: PSM, Manager, Administrator

Portfolio Analytics provides an at-a-glance view of your entire partner portfolio — key metrics, trends, and distributions that help you prioritize your time and attention.

## Dashboard Overview

Navigate to **Measure > Portfolio Analytics** to see your portfolio dashboard.

<!-- ![Portfolio analytics dashboard](images/portfolio-analytics.png) -->

The dashboard includes:

- **Partner count** by tier and path stage
- **Revenue metrics** — Total pipeline value, sourced vs influenced
- **Health distribution** — How many partners are healthy, at risk, or critical
- **Task summary** — Open tasks, overdue tasks, completion rates
- **Upcoming events** — Scheduled QBRs, enablement sessions, deadlines

## Trend Analysis

View trends over time for key metrics:

- Pipeline growth or decline
- Certification velocity across the portfolio
- Stage advancement rate
- Health score movement

## Filtering

Analytics can be filtered by:

- Partner tier
- Path enrollment
- Assigned PSM (for managers viewing across portfolios)
- Date range

> [!TIP]
> Use portfolio analytics to prepare for leadership reviews. The dashboard provides the data you need to tell the story of your portfolio's health and trajectory.
