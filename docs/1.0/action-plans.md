# Action Plans

Action Plans provide a structured way to define and track strategic initiatives for a partner. Unlike individual tasks, an action plan groups related items into a cohesive development plan.

## Creating an Action Plan

1. Navigate to the partner's profile
2. Go to **Plan > Action Plans**
3. Click **New Action Plan**
4. Enter a title and description for the plan
5. Add individual action items with owners and due dates

<!-- ![Action plan form](images/action-plan-form.png) -->

## Action Items

Each action plan contains one or more action items. An action item includes:

- Title and description
- Assigned owner
- Due date
- Status (pending, in progress, completed)

## Tracking Progress

The action plan view shows overall progress as a percentage of completed items. This gives a quick visual indicator of how the plan is progressing.

> [!TIP]
> Action plans are ideal for QBR follow-ups. After a QBR session, create an action plan with the agreed-upon next steps and assign them to the appropriate owners.

## Linking to QBRs

Action plans can be referenced in QBR sessions to track commitments made during quarterly reviews. This creates a clear chain of accountability from discussion to execution.
